## 📚 技术亮点（面试准备）

### 1. MCP 工具设计
**问题**：为什么要设计两个独立的工具（`search_nodes` 和 `open_nodes`）？

**回答**：
- `search_nodes`：轻量级搜索，返回基本信息，用于高亮显示
- `open_nodes`：获取完整详情，只在用户点击时调用
- 遵循"按需加载"原则，避免一次传输过多数据

### 2. 前后端数据格式对齐
**问题**：如何保证前后端数据格式一致？

**回答**：
- 前端定义 TypeScript 接口
- 后端按接口返回数据
- 使用测试脚本验证字段完整性
- 典型的"契约式设计"（Contract-First Design）

### 3. D3.js 力导向图优化
**问题**：如何避免节点重叠？

**回答**：
- 使用 `d3.forceCollide()` 碰撞检测
- 调整 `charge` 力（排斥力）为 -300
- 设置 `link` 距离为 100

## ⚠️ 已知限制

3. **关系类型固定** - 不支持用户自定义关系类型
